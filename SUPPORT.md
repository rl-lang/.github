# Support

- How do I...: ask on [Discord](https://discord.gg/AHvVbKjJN7) or
  [GitHub Discussions](https://github.com/orgs/rl-lang/discussions).
- Something is broken: open an issue in the right repo (see
  CONTRIBUTING.md for the map), using the bug template.
- Something is insecure: see SECURITY.md, never a public issue.
- Something is slow: benchmark first (`rl run` with timing), then open
  an issue with numbers.

Maintainers are volunteers. Well-shaped reports (version, repro,
expected vs actual) get answered first.
