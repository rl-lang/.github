# Code of Conduct

Talk about the code, not the person. Disagree with ideas, stay off
people. No harassment, no slurs, no drive-by cruelty, no spam.

Maintainers enforce this in issues, PRs, discussions, and the Discord.
First offense gets a warning, repeat offenses get a ban. Decisions are
final but appealable once, in private, to another maintainer.

If someone is making the space worse, report it: open a private
security advisory on `rl-lang` or message a maintainer on Discord.
We will keep it confidential.
